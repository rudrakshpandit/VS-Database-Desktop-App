## 4. Standalone Runtime Application Verification (Port 8769)

To guarantee that the application executable can launch and read data from a restored backup:

1. **Environment Setup:** The restored database was placed in `backups/phase14b_sandbox_restore/data/vs_database_desktop.db`.
2. **Sidecar Process Launch:**
   - Binary: `dist/server_sidecar.exe`
   - Working Directory: `backups/phase14b_sandbox_restore`
   - Port: `8769` (Dedicated sandbox port, preventing any port collision with legacy on 8767 or V2 on 8768)
   - Handshake Token: Generated ephemeral 256-bit token
3. **Health Probe:**
   - Request: `GET http://127.0.0.1:8769/api/desktop/health`
   - Response: `{"ok": true, "name": "VS Database Desktop"}`
   - Result: **HTTP 200 OK**.
4. **Data Query Probe:**
   - Request: `GET http://127.0.0.1:8769/api/clients?limit=5`
   - Response: 5 client records retrieved from restored database.
   - Result: **HTTP 200 OK**.
5. **Controlled Shutdown:**
   - Request: `POST http://127.0.0.1:8769/api/desktop/shutdown`
   - Result: Process exited with returncode 0.
